# 🎛️ Audiophile FLAC to WAV CUE-Splitter & Web-Player

Интерактивный веб-плеер и высокоточный аудиофильский конвертер, написанный на **Python** с использованием **Streamlit** и **FFmpeg**. Позволяет сканировать локальную музыкальную коллекцию, парсить CUE-листы, нарезать FLAC-аудиообразы на треки и слушать их превью прямо в браузере.

## 🚀 Основные возможности
* **Динамическая библиотека:** Автоматическое сканирование папки `Music` и вывод списка доступных альбомов.
* **CUE Sheet Парсер:** Чтение метаданных, структуры треков, имен исполнителей и точного времени старта сэмплов из `.cue` файлов.
* **Аудиофильская нарезка:** Декодирование FLAC в оригинальное несжатое качество **WAV (PCM 16-бит, 44.100 Гц)** бит-в-бит без потерь.
* **Оптимизированный веб-плеер:** Автоматическая генерация легких MP3-превью (192 kbps) с помощью FFmpeg для мгновенного прослушивания треков в браузере без задержек буферизации.
* **Вшивание метаданных:** Автоматическая запись тегов (`Title`, `Artist`, `Album`, `Track Number`) в сгенерированные файлы превью.
* **Визуализация:** Автоматический поиск и отображение обложек альбомов из папки `Art` или структуры диска.

## 🛠️ Стек технологий
* **Язык:** Python 3.12+
* **Интерфейс:** Streamlit
* **Обработка аудио signals:** SoundFile, Mutagen
* **Медиа-движок:** FFmpeg (через подпроцессы Python `subprocess`)

## 💻 Установка и запуск

1. Установите **FFmpeg** в вашу систему и добавьте путь к папке `bin` в системную переменную `PATH`.
2. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd FlacToWav
   ```
3. Установите необходимые Python-зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Создайте структуру папок для музыки:
   ```text
   Music/
   └── Название Альбома/
       ├── CDImage.flac
       ├── CDImage.cue
       └── Art/
           └── cover.jpg
   ```
5. Запустите веб-сервер приложения:
   ```bash
   streamlit run app.py
   ```
